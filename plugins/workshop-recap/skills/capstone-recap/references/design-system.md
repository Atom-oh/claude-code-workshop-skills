# Capstone recap — design system

Read this before writing any CSS. The non-negotiable is **committing to one direction and
executing every detail of it** — not this exact theme. A page assembled from generic defaults
reads as machine-generated and undercuts work the participant spent two days on.

The reference direction here is a **"lab notebook" system**: warm paper, warm ink, one accent,
mono for every filename and number. It suits an accomplishment record. A capstone with its own
identity (a game, a generative-art gallery) may reuse *that project's* palette instead — that's
better, not worse, as long as it's deliberate and passes §6.

---

## 1. Tokens

One `:root` block. Components reference **only the derived aliases**, never the raw ramps — that's
what lets a whole page re-theme by editing eight lines.

```css
:root{
  /* paper surfaces */
  --paper-0:#faf8f3; --paper-1:#f2eee4; --paper-2:#e9e3d6;
  /* warm ink ramp */
  --ink-0:#1b1a17; --ink-1:#3c3833; --ink-2:#6a6359; --ink-3:#9a927f;
  /* single accent — pick ONE and use it only for brand/active/CTA */
  --accent-600:#8c3a1f; --accent:#b4502c; --accent-400:#d16f4e; --accent-100:#f6e2d8;
  /* semantic, verified states only */
  --ok:#2f5d50; --warn:#8a6d1f;
  /* derived aliases — the ONLY names components use */
  --bg:var(--paper-0); --surface:var(--paper-1); --sunken:var(--paper-2);
  --text:var(--ink-0); --muted:var(--ink-2); --faint:var(--ink-3);
  --line:#e2dccb; --line-2:#cfc7b2;
  --shadow-card:0 1px 2px rgba(27,26,23,.04), 0 8px 28px rgba(27,26,23,.06);
  --maxw:1100px; --r:14px;
}
```

**Color philosophy.** Functional color only: accent = brand/active/CTA, `--ok`/`--warn` = real
verified states (a passing check, a caveat). Everything else is plain ink. Dominant neutrals with
one sharp accent read as considered; an evenly rainbow palette reads as a template.

**Contrast trap.** `--faint` (`--ink-3`) is ~3.1:1 on paper and **fails WCAG AA** — decorative or
large-text only, never body copy or a caption you expect people to read. Body text uses `--text`,
secondary uses `--muted` (~4.7:1, passes). Never `#999`/`#b0b0b0`.

## 2. Typography

**Pair, don't default.** Inter / Roboto / Arial / system-only as the *display* face is the single
loudest "generated by a machine" signal. Use three roles:

```css
--display:"Newsreader","Source Serif 4",Georgia,serif;   /* headings */
--sans:"Public Sans","Pretendard Variable",Pretendard,-apple-system,system-ui,sans-serif;
--mono:"JetBrains Mono",ui-monospace,SFMono-Regular,monospace;
```

- **A full system fallback in every stack is mandatory.** A recap page is often opened from a
  local file with flaky or no network; CDN fonts are optional, the fallback is not.
- Latin-only display faces (Newsreader, Source Serif) don't cover Korean — for KR headings use the
  sans at weight 800 rather than letting the serif silently fall back mid-heading.
- `--mono` carries **every** file path, command, hook name, and metric. That's the visual grammar
  that makes an evidence-based page feel evidence-based.
- `font-variant-numeric: tabular-nums lining-nums` on any stats strip so digits align in columns.
- Headings `text-wrap: balance`; body/lead paragraphs `text-wrap: pretty`.
- Fluid headline: `font-size: clamp(30px, 4.8vw, 52px)`.

**The measure gotcha — most common reason a generated page looks half-empty.** Cap line length
(`max-width: 62ch`) **only** on a narrow prose column. Applying it to a block that spans the full
content column strips the text to roughly half width and leaves a huge dead gutter. On full-width
section headers and grid containers, set `max-width: none`.

## 3. Layout & responsive

A single centered column with a vertical section spine. **Two tiers, breakpoint 768** — a recap
page has no dense spec table to restack, so brochure's three-tier 640/1024 split buys nothing.
`check_recap_html.py` defaults to `--mobile-breakpoint 768` to match.

```css
.wrap{max-width:var(--maxw); margin:0 auto; padding:0 24px}
@media (max-width:768px){ .wrap{padding:0 18px} .grid-2,.grid-3{grid-template-columns:1fr} }
```

- **Capabilities grid**: `grid-template-columns: repeat(auto-fill, minmax(260px, 1fr))` — adapts
  from 1 to 4 columns without a media query per breakpoint.
- **Stats strip**: `repeat(auto-fit, minmax(9rem, 1fr))`, tabular numerals, label under value.
- **Demo captures**: `figure > img{width:100%;height:auto;border:1px solid var(--line);border-radius:12px}`
  \+ `<figcaption>` at 13px `--muted`. Always `loading="lazy"` and a descriptive `alt`.
- **Code/spec excerpts**: `pre{background:var(--sunken);overflow-x:auto;padding:16px;border-radius:10px}`.
  A `<pre>` must scroll inside itself — never let it push the page into horizontal scroll.

## 4. Section conventions

The spine is in `SKILL.md`. Two conventions matter to the checker and to honesty:

- Every capability row/card names its **real source file** in `--mono`
  (`.claude/agents/reviewer.md`, `.claude/settings.json → PostToolUse`). A capability with no
  source file doesn't get a row.
- A stat tile with no real number is **omitted**. Never render `0`, `—`, or "unknown" — an absent
  tile reads as "not applicable", a zero reads as "failed".

---

## 5. Accessibility

Not optional; the checker enforces most of it.

- Skip link as the first focusable element: visually hidden, visible on `:focus`, targeting `#main`.
- `:focus-visible{outline:2px solid var(--accent); outline-offset:3px}` — default rings are nearly
  invisible on warm paper.
- `@media (prefers-reduced-motion: reduce)` zeroes transitions/animations. If the page embeds SVG
  with `<animate>` (a generative-art capstone might), CSS **cannot** stop SMIL — remove the
  elements in JS under the same query.
- Contrast ≥4.6:1 for body text (see §1).
- Decorative SVG: `aria-hidden="true" focusable="false"`. A meaningful diagram gets a real `alt`
  or `aria-label` describing what it shows, not a filename.
- Tap targets ≥40px; primary buttons full-width on mobile.
- Any table gets a `<caption>` (may be `.sr-only`).

## 6. CSS gotchas that bite every time

1. **Utility-margin reset trap.** `.wrap{margin:0 auto}` plus a later `.cta{margin:40px 0 0}` on
   the *same element* resets left/right to `0` and jams the block against the left edge (equal
   specificity → source order wins). Write `margin:40px auto 0`, or set only `margin-top`.
2. `text-align:center` does **not** center a fixed-width child — that needs `margin:0 auto`.
3. Without `*{box-sizing:border-box}`, any padded full-width element overflows the viewport.
4. Scroll-reveal that starts at `opacity:0` leaves the whole page blank if JS doesn't run. Ship a
   `<noscript><style>.reveal{opacity:1!important;transform:none!important}</style></noscript>`
   fallback, and honor reduced-motion.
5. Absolute local paths (`/home/you/...`) must never appear in visible text — the checker FAILs on
   this. Show repo-relative paths; this page gets screenshotted and shared.
6. **The key→path row trap.** A recap page is mostly `label → file path` rows, and the obvious
   `display:flex; justify-content:space-between` leaves a disconnected gulf on desktop and crushes
   the path against the right edge on mobile (a long unbroken `src/engine.js — …` string won't wrap
   where you want it to). Use a two-column grid that collapses instead:
   ```css
   .kv li{display:grid; grid-template-columns:minmax(7rem,auto) 1fr; gap:6px 20px;
          padding:11px 0; border-bottom:1px solid var(--line)}
   .kv .v{font-family:var(--mono); font-size:13px; color:var(--muted);
          overflow-wrap:anywhere; text-align:right}
   @media (max-width:768px){
     .kv li{grid-template-columns:1fr}      /* value drops to its own line */
     .kv .v{text-align:left}
   }
   ```
   `overflow-wrap:anywhere` is what keeps a long path from forcing horizontal scroll. Verify at
   390px that `document.documentElement.scrollWidth === clientWidth`.

---

## 7. Content integrity

- Every claim traces to a real file, a verified URL, or the participant's own words. Nothing else
  goes on the page.
- Don't inflate: no invented feature lists, no invented metrics, no naming AWS services or a
  vector store the project doesn't actually use.
- Strip PII/secrets from excerpts and screenshots — account IDs, ARNs, internal hostnames/CIDRs,
  tokens in URLs. **A screenshot bakes these into pixels where no text scan can find them**, so
  eyeball every capture manually before the page is shared.
